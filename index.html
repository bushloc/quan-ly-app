Tracking API (USPS · UPS · FedEx)

Khoá chỉ lưu trên máy này. Không có khoá thì dùng 17track.

Cách lấy khoá miễn phí
  1. USPS: đăng ký tại developers.usps.com → Apps → tạo App → chép Consumer Key (dán vào ô ID) và Consumer Secret.
  2. UPS: đăng ký tại developer.ups.com → Create App → thêm sản phẩm Tracking và OAuth → chép Client ID và Client Secret.
  3. FedEx: đăng ký tại developer.fedex.com → Create Project → chọn Track API → chép API Key (ô ID) và Secret Key. Lấy khoá Production, không phải Test.
